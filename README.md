# 🎥 API de Streaming de Arquivos

API para upload, autenticação e streaming de arquivos de mídia (foco em vídeos), construída com Java + Spring Boot. Projeto de estudo com arquitetura modular, segurança, cache, otimização e deploy com Docker e AWS.

- Docker instalado

## Instalação
1. Certifique-se de que o Docker está em execução na sua máquina.
2. Clone este repositório em sua máquina local:
git clone https://github.com/estrela2704/media-streaming-api.git
3. Navegue até o diretório onde o repositório foi clonado:
   cd media-streaming-ap
4. No terminal, execute o comando Docker Compose para iniciar a aplicação:
   docker-compose up -d
   
## Acesso
Após a inicialização, a documentação Swagger da aplicação estará disponível na seguinte URL:
- http://localhost:8080/swagger-ui.html
